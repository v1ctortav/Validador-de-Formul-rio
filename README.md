# 📋 Validador de Formulário de Cadastro
Mini projeto focado na **validação de formulários** utilizando JavaScript.
## 🚀 Tecnologias Utilizadas
* **HTML5**
* **CSS3**
* **JavaScript**
## ⚙️ Funcionalidades
* **Validação de Campos Vazios**: Verifica se todos os campos foram preenchidos antes do envio.
* **Validação de Usuário**: Restringe o uso de caracteres e limita o tamanho mínimo.
* **Check de Senha**: Garante que os campos das senhas sejam idênticos.
* **Validador de CPF**: Implementado para verificar se o CPF informado é válido.
